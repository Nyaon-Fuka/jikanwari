# じかんわり — 1DAY管理アプリ

24時間を「①わけわけタイム（配分）」と「②じかんわり計画（時間帯ごとの予定）」の2つのモードで管理できる、スマホ向けの1日管理アプリです。

- データはすべて**あなたの端末の中（localStorage）**に保存されます。サーバーには送信されません。
- ②の「計画」データは、**その日が終わると自動的に消えます**（記録を残さない仕様・ストレージ節約とプライバシーのため）。①の配分設定やカテゴリ名は消えずに残ります。
- インターネットがない場所でも開けるように、オフライン対応（Service Worker）にしています。

## ファイル構成

```
jikanwari/
├── index.html              アプリ本体（これを開くだけで動きます）
├── manifest.json            PWA設定（アプリ名・色・アイコン）
├── sw.js                     オフラインキャッシュ用スクリプト
├── icon-192.png              アイコン（192×192）
├── icon-512.png              アイコン（512×512）
├── icon-512-maskable.png     アイコン（Android等の角丸対応用）
├── apple-touch-icon.png      アイコン（iPhoneホーム画面用・180×180）
└── README.md                 このファイル
```

## GitHubで公開する手順（GitHub Pages）

1. GitHubで新しいリポジトリを作成します（例：`jikanwari`）。
2. このフォルダの中身（`index.html` や `manifest.json` など）をすべてリポジトリにアップロードします。
   - GitHubのウェブ画面から「Add file」→「Upload files」でこのフォルダの中身をまとめてドラッグ＆ドロップするのが簡単です。
   - フォルダごとではなく、**中のファイルを直接**リポジトリ直下に置いてください。
3. リポジトリの「Settings」→ 左メニューの「Pages」を開きます。
4. 「Build and deployment」の「Source」で **Deploy from a branch** を選び、ブランチを `main`（またはご自身の既定ブランチ）、フォルダを `/ (root)` に設定して「Save」します。
5. 数分待つと、ページ上部に公開URLが表示されます（例：`https://ユーザー名.github.io/jikanwari/`）。

以後、内容を修正したいときはファイルを上書きしてコミットするだけで、自動的にサイトへ反映されます。

## iPhoneのホーム画面に追加する手順

1. iPhoneの**Safari**（Chromeなど他のブラウザは不可）で、公開したURLを開きます。
2. 画面下部の共有アイコン（□に上矢印）をタップします。
3. メニューを下にスクロールし、「**ホーム画面に追加**」をタップします。
4. 名前を確認して（そのままで「じかんわり」になります）「追加」をタップします。
5. ホーム画面にアイコンが追加され、アプリのように起動できるようになります。

一度ホーム画面から開いておくとオフラインでも開けるようになります。

## 使い方のポイント

- 初回は⚙（設定）から、12色それぞれに好きな名前（睡眠・仕事・食事など）をつけてください。一度決めれば、次回以降は自動で表示されます。
- **①わけわけタイム**：24時間をカテゴリごとに何時間使うか配分します（順不同・24時間ぴったりでなくてOK）。
- **②じかんわり計画**：「何時〜何分に何をやるか」を予定として入力します。①より短くても長くても構いません。完了したらチェックを入れられます。この予定データはその日限りです。
- **カレンダー**：週／月／3ヶ月表示に対応。日付をタップすると、その日の配分・計画の確認や、他の日への「コピー」ができます。コピーは「特定の日」「曜日を指定」「期間を指定」の3パターンに対応し、貼り付け後も個別に修正できます。

## 注意事項

- ブラウザの「サイトデータを消去」や「シークレットモード」で使うと、保存したデータが消えることがあります。
- 端末やブラウザを変えると、データは引き継がれません（同じ端末・同じブラウザ内でのみ保存されます）。
